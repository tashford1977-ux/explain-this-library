# Explain This library

Standard explanations for common forms, used by the Explain This app.

- Written from public guidance only. It contains **no personal information** and must never contain any.
- `forms.json` is downloaded by the app and kept on each phone. The app compares a form's wording on the phone; nothing from a person's documents is ever sent here.
- To add or change a form, edit `forms.json` and raise `version`.
